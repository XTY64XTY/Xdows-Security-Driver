# Safe Driver Test Tools

Use this directory for locally built helper tools used by the VM validation matrix.

Allowed examples:

- A benign unsigned process launcher.
- A benign file-create/write/rename exerciser.
- A handle-open helper that targets only the local Xdows Security test process.
- A DLL-load helper that uses a local benign test DLL.

Do not commit malware, exploit code, credential material, or tools that target third-party processes.
